API contatti

WordPress, Meta e altri sistemi possono creare o aggiornare contatti con una richiesta autenticata.

POST /api/ingest/contacts
Authorization: Bearer <CRM_API_KEY>
Idempotency-Key: <identificativo-univoco>
Content-Type: application/json

{
  "source": "wordpress",
  "email": "nome@example.com",
  "firstName": "Nome",
  "tags": ["landing"]
}

WhatsApp aggiorna automaticamente la rubrica quando arriva un messaggio.
