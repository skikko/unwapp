# Modal

Dialogo modale per conferme e form brevi (Nuovo contatto, Nuovo account, Crea BOT).

- Larghezza 520px (form fino a 640px), raggio `radius-lg`, `shadow-lg`, overlay navy al 44%.
- Titolo come domanda per le conferme; il bottone ripete l'azione e l'oggetto ("Elimina 2 contatti"), mai "OK".
- Focus intrappolato, Esc chiude, focus restituito al trigger. Form lunghi (template email, sequenze) vanno in una pagina, non in un modal.
