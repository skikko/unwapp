# EmptyState

Stato vuoto: icona su `accent-soft`, titolo, una frase che spiega il prossimo passo, azione.

- Usarlo per liste vuote, ricerche senza risultati ("Nessun contatto corrisponde ai filtri" + "Rimuovi filtri") e pannelli non selezionati.
- Il testo spiega cosa succede dopo l'azione, non ripete il titolo.
- Nel pannello conversazione vuoto: "Seleziona una conversazione" senza azione, icona messaggio.
