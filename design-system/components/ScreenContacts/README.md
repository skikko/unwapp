# ScreenContacts

Composizione di riferimento per le pagine elenco del CRM (Contatti, Liste, Template, Sequenze, Invii).

- Shell + PageHeader + StatCard opzionali + Card con DataTable.
- Cambiamenti rispetto alla v1: sidebar CRM uniformata alla shell, filtri a chip applicati subito al posto del form a 5 campi con "Applica filtri", tre bottoni CSV raggruppati in "Importa / Esporta", valori vuoti come trattino invece di badge "n/a", tabella senza scroll orizzontale della pagina.
