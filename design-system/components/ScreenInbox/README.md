# ScreenInbox

Composizione di riferimento per Conversazioni del WhatsApp Manager.

- Tre pannelli a tutta altezza sotto la topbar: lista (`pane-list`), thread, dettaglio contatto (`pane-detail`, richiudibile).
- Il BOT si sceglie con una select nell'header della lista: la colonna BOT dedicata della v1 viene rimossa e la lista guadagna 300px.
- Filtri rapidi a segmented (Tutte, Non lette, Mie, Chiuse) al posto delle due select "Tutti gli stati / Tutti i broadcast"; il filtro per broadcast va nel menu avanzato.
- L'header della conversazione mostra la scadenza della finestra 24h e le azioni Assegna / Chiudi.
