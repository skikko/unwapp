# Tabs

Schede sottolineate (`un-tabs`) per viste della stessa risorsa, e controllo segmentato (`un-segmented`) per opzioni di visualizzazione.

- Tabs: filtri principali di una lista (Tutte, Non lette, Chiuse) o sotto-sezioni di un record. Indicatore `accent` 2px.
- Segmented: 2-4 opzioni mutuamente esclusive che cambiano la vista, non i dati (densita', periodo).
- Non usare tab a pillola per la navigazione tra sezioni: quella va in Sidebar.
