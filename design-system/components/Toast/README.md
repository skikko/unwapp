# Toast

Conferma temporanea dell'esito di un'azione, in basso a destra, 5 secondi.

- Navy con icona `accent-on-navy`, titolo e dettaglio opzionale, azione "Annulla" quando l'operazione e' reversibile.
- Errori che richiedono intervento: Callout `--danger` nella sezione, non toast.
- Massimo 3 impilati; `role="status"` (o `alert` per gli errori).
