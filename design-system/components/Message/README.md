# Message

Bolla del thread e composer.

- `un-msg--in` (contatto, bianco a sinistra), `un-msg--out` (operatore, navy a destra), `un-msg--bot` (BOT, `accent-soft` a destra). Meta: orario, autore BOT, stato di consegna in parole.
- Separatori di giorno `un-daysep`. Larghezza massima 64% del thread.
- Composer: allega, template rapidi, textarea che cresce fino a 6 righe, Invia (Invio invia, Shift+Invio va a capo). Fuori dalla finestra di 24h il composer e' sostituito da un Callout con "Invia template".
