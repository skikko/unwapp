# Topbar

Barra superiore della shell: breadcrumb a sinistra, ricerca globale e notifiche a destra.

- Breadcrumb: app > sezione > record. L'ultimo elemento in `strong`.
- Ricerca globale con scorciatoia Cmd K: apre una command palette (Menu in overlay) che cerca contatti, conversazioni e comandi.
- Sticky, alta `topbar-height`. Non contiene la navigazione tra sezioni: quella sta in Sidebar.
