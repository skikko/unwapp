# Conversation

Voce della lista conversazioni: avatar, nome o numero, orario, anteprima, non letti.

- Griglia a tre colonne; non letta = `un-convo--unread` (anteprima in `ink` 600) + `un-count`. Aperta = `aria-selected="true"`.
- Senza nome mostrare il numero in formato internazionale e le prime cifre nell'avatar.
- Messaggi del BOT preceduti da "BOT:" nell'anteprima.
- Lista virtualizzata; aggiornare solo la voce cambiata.
