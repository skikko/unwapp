# StatCard

KPI compatto: label, valore `metric`, variazione opzionale.

- Contenitore `un-stats` (griglia auto-fit, min 180px), ogni voce `div.un-card.un-stat`.
- Massimo 4 per riga e solo dove il numero guida una decisione (code di invio, contatti nuovi). Non ripetere numeri gia' visibili nel pager della tabella.
- Valore cliccabile: tutta la card diventa link al filtro corrispondente.
