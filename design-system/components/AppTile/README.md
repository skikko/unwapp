# AppTile

Ingresso a un'applicazione nel launcher Home: sigla, nome, descrizione, freccia.

- Tutta la tile e' un link. Variante `--dark` per il CRM come nella v1; WhatsApp su `surface`.
- Riga orizzontale compatta al posto delle card alte 340px della v1: le app sono visibili senza scroll anche con l'area Amministrazione.
