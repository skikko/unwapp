# Stepper

Avanzamento di un wizard in 3-5 passi: completati, corrente, futuri.

- Lista ordinata `ol.un-stepper` con `li.un-step` e modificatori `--done` / `--current`; aggiungere `aria-current="step"` al corrente.
- I passi completati sono cliccabili per tornare indietro; i futuri no.
- Usato in Nuovo broadcast e Importa CSV.
