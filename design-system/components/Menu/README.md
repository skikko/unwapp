# Menu

Lista di azioni in popover: azioni secondarie, menu di riga, switcher di workspace, command palette.

- Voci con icona 16px, label, scorciatoia opzionale in `un-kbd`. Separatori `un-menu__sep` tra gruppi.
- Navigabile da tastiera (frecce, Invio, Esc). Azioni distruttive in fondo, dopo un separatore.
