# Callout

Messaggio in pagina legato a una sezione: info (default), `--warn`, `--danger`, `--success`.

- Icona colorata di stato, titolo in `ink`, testo in `ink-soft`, azione opzionale a destra.
- Per condizioni persistenti che bloccano o spiegano (configurazione mancante, finestra 24h WhatsApp). Per esiti di un'azione usare Toast.
- Sostituisce il tooltip scuro che nella v1 copriva l'header della pagina Broadcast.
